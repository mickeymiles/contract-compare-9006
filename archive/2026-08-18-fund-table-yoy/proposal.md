# 提案：资金占用表格增加同比分析与变化率

> 变更编号：`20260818-fund-table-yoy`
> 作者：AI 助手 | 日期：2026-08-18 | 状态：已批准

## 背景与问题

资金占用总览已通过 FR-13 提供同比 KPI 卡与月度同比柱状图，但明细表（资金占用明细）与客户集合表格仍只展示本期绝对值，无法逐合同/逐客户集合识别"占用同比扩大/缩小"的高风险对象。用户要求：**表格也需要增加同比分析，以及变化率，同时变化率颜色要根据升降有区分**。

## 目标

1. 资金占用明细表每行增加"上年同期占用"与"同比变化率"列，变化率按升降着色（占用升=红、降=绿，与 KPI 语义一致）。
2. 客户集合表格同样增加两列，支持按客户集合快速识别占用同比恶化对象。
3. 下钻清单（`/api/fund/dim/drill`）与宽表查询（`/api/fund/metrics`）同步携带上年同期占用。

## 变更范围

### In Scope

- 后端 `fund_analyze`：每合同计算上年同期（上年同日）FIFO 占用，写入明细行与宽表 `fund_metrics.prev_occupy`。
- 后端 `fund_metrics`/`_fund_dim_aggregate_inner`/`fund_dim_drill`：输出上年同期占用。
- 前端明细表、客户集合表格：新增两列，变化率着色。
- 规格 FR-13 追加表格同比场景；测试补充；归档。

### Out of Scope

- 付款/回款/净现金流在表格中的逐行同比（仅占用同比）。
- 风险 tab 预警清单表格的同比。
- 表格同比的导出列调整（`/api/fund/analyze/export` 保持现状）。

## 接口与数据契约

`POST /api/fund/analyze` 明细行新增字段：

```json
{
  "合同编号": "HT-001",
  "当前资金占用": 1200000,
  "上年同期占用": 1500000
}
```

`GET /api/fund/metrics` 明细行新增 `"上年同期占用"`；
`GET /api/fund/dim/aggregate?dim=customer_key` 每行新增 `"prev_occupy"`；
`GET /api/fund/dim/drill` 清单行新增 `"上年同期占用"`。

前端变化率口径：`pct=(cur-prev)/prev*100`；`prev=0 且 cur>0` 显示"新增占用"（红色）；`prev=0 且 cur=0` 显示 `—`。颜色语义（占用类）：上升/新增=红 `#ff4d4f`，下降=绿 `#52c41a`，持平=中性色。

## 涉及规格条目

- `CC-006 FR-13`：MODIFIED（追加明细表/客户集合表格同比场景）

## 验收标准

- [ ] `fund_analyze` 明细行含"上年同期占用"，与 `yoy.occupy_prev` 口径一致（按合同加总相等）
- [ ] 前端明细表与客户集合表格展示同比变化率列，升红降绿着色
- [ ] 全量测试通过（含新增用例）

## 风险与兼容性

- 宽表 `fund_metrics` 新增列通过 `ALTER TABLE` 幂等迁移（models.py dim_cols 追加），兼容旧库。
- 旧快照（`fund-occupancy`）不含新字段时前端需兜底（`prev` 缺省为 0）。
