# 提案：签单毛利率模块新增部门 × 区域二维热力图

> 变更编号：`2026-08-20-gross-heatmap`
> 作者：AI 编程助手 | 日期：2026-08-20 | 状态：已实现并归档（delta 已合并至 `specs/008-gross-heatmap/spec.md`）

## 背景与问题

当前签单毛利率统计页面 (`/gross`) 已提供年度、区域、部门三个一维汇总表。业务侧希望像参考图片（省分 × 行业毛利率同比变化热力图）一样，在部门维度上增加二维交叉热力图，直观展示不同部门在不同区域的签单毛利率表现及同比变化，便于定位高增长/下降的业务板块。

## 目标

1. 在签单毛利率页面增加一个**部门 × 区域**的二维热力图。
2. 每个单元格同时展示 2026 年签单毛利率和较 2025 年的同比变化百分点。
3. 按同比变化幅度进行颜色分档（绿→黄→橙→红），空白单元格用灰色表示无数据。
4. 保持现有年度/区域/部门表格不变。

## 变更范围

### In Scope

- ETL `run_etl_gross_margin`：新增 `dept_region` 维度聚合。
- API `/api/gross/metrics`：新增 `dept_region_rows` 返回。
- 前端 `frontend/gross.html`：新增热力图渲染区域。
- 前端 `frontend/common.css`：新增热力图单元格样式。

### Out of Scope

- 不修改现有 `year`、`region`、`dept` 三个维度的数据与展示逻辑。
- 不新增数据源字段，仅基于已有的 `部门` 和 `区域` 字段交叉聚合。
- 不实现点击单元格下钻等二次交互。

## 接口与数据契约

`/api/gross/metrics` 在现有响应中追加字段：

```json
{
  "dept_region_rows": {
    "regions": ["华北", "华东", ...],
    "depts": ["部门A", "部门B", ...],
    "cells": {
      "部门A": {
        "华北": { "rate2026": 0.184, "diffPct": 2.9, "hasData": true },
        "华东": { "rate2026": null, "diffPct": null, "hasData": false }
      }
    },
    "totals": {
      "byDept": { "部门A": { "rate2026": 0.21, "diffPct": 1.5 } },
      "byRegion": { "华北": { "rate2026": 0.22, "diffPct": 3.1 } }
    }
  }
}
```

- `rate2026`：2026 年签单毛利率（小数，前端转百分比）。
- `diffPct`：2026 较 2025 同比变化百分点（带符号，如 `+2.9` / `-1.8`）。
- `hasData`：该交叉维度是否有 2026 或 2025 数据；无数据单元格显示空白并置灰。

## 风险与兼容性

- 风险：历史数据年份可能不是 2025/2026；若不存在则热力图全部空白。缓解：代码保持与现有 API 一致的 2025/2026 硬编码逻辑，实际展示取决于数据源中的年份。
- 兼容性：ETL 新增写入 `dept_region` 记录，不删除/修改既有 `year/region/dept` 记录；API 仅新增字段，不改动既有字段结构。
