# CC-008 签单毛利率二维热力图分析

## Requirement

签单毛利率统计页面应新增一个部门 × 区域二维热力图，帮助用户快速识别不同部门在不同区域的毛利率水平及同比变化趋势。

## FR-1 热力图展示

系统应在签单毛利率页面 (`/gross`) 中展示一个部门 × 区域的二维热力图。

### FR-1.1 维度定义

- 行维度：部门（dept）。
- 列维度：区域（region）。
- 行首列显示部门名称；最后一行为「小计」行，显示按区域聚合的总计。
- 列首行显示区域名称；最后一列为「小计」列，显示按部门聚合的总计。

### FR-1.2 单元格指标

每个单元格应同时展示两项指标：

1. 2026 年签单毛利率（百分比，保留一位小数）。
2. 2026 年较 2025 年毛利率的变化百分点（带正负号，保留一位小数，如 `+2.9pct` / `-1.8pct`）。

### FR-1.3 空白单元格

当某部门在某区域无 2025 或 2026 签约数据时，该单元格应显示为空白灰格，并在页面说明中提示「空白 = 未签约，不纳入比较」。

## FR-2 颜色分档

单元格应根据同比变化百分点 (`diff`) 使用颜色分档：

- `diff >= +20.0`：深红色。
- `+5.0 <= diff < +20.0`：红色。
- `+2.0 <= diff < +5.0`：浅红色。
- `-2.0 < diff < +2.0`：黄色。
- `-5.0 < diff <= -2.0`：浅绿色。
- `-20.0 < diff <= -5.0`：绿色。
- `diff <= -20.0`：深绿色。
- 无数据：灰色。

颜色应与现有页面深色主题协调，单元格文字保持可读。

## FR-3 数据来源

热力图数据应来自 `indicator_metrics` 表中 `job_key='gross-margin'`、`dim_type='dept_region'` 的记录。每个记录代表某部门在某区域、某年份的聚合毛利指标。

## FR-4 兼容性与扩展

- 热力图不得影响现有年度、区域、部门三个一维表格的展示与交互。
- 当 `dept_region_rows` 字段不存在或为空时，热力图区域应显示占位提示（如「暂无数据」），不得报错。

## GIVEN / WHEN / THEN

### TC-1 正常展示

GIVEN 系统中已有 2025/2026 年按部门和区域交叉的合同数据  
WHEN 用户访问签单毛利率页面  
THEN 页面渲染部门 × 区域热力图；每个有数据单元格显示 2026 毛利率与同比变化百分点；单元格颜色与 diff 范围匹配。

### TC-2 空白单元格

GIVEN 某部门在某区域缺少 2025 或 2026 年数据  
WHEN 热力图渲染到该单元格  
THEN 单元格显示为灰色空白，不显示数值。

### TC-3 无数据兜底

GIVEN 系统未执行新版 ETL，`indicator_metrics` 中无 `dim_type='dept_region'` 记录  
WHEN 用户访问签单毛利率页面  
THEN 热力图区域显示「暂无数据」占位，页面其他部分正常。

### TC-4 API 数据一致性

GIVEN 后端已生成 `dept_region` 聚合数据  
WHEN 调用 `/api/gross/metrics`  
THEN 响应包含 `dept_region_rows`，其 `cells`、`totals` 数值与 ETL 写入的金额一致。
