📊 运营管理工作台 — 用户手册

最后更新：2026-08-14 | 暗色主题 B端运维风格

一、系统概述

本工作台是经营业务运营管理的一站式入口，覆盖合同、回款、资金、毛利等核心经营数据分析。顶部左侧为渐进式面包屑导航（运营管理 › 当前模块），点击「运营管理」随时返回门户首页。

模块用途数据来源
📁 数据源管理上传维护各业务数据表，多版本管理总合同表 / 项目里程碑表 / 付款明细表 / 收款明细表
💰 回款周期分析合同回款全链路周期追踪、逾期预警总合同表 + 项目里程碑表
📊 资金占用 · 周转率资金占用分析、周转效率、现金流健康度付款明细表 + 收款明细表
📈 签单毛利率统计按项目/客户/时间多维度毛利率分析总合同表（签单毛利字段）
📋 项目决算报告项目收支决算、成本归集、利润核算即将上线
🔍 采购合同比对合同基准 vs 供应商报价智能比对合同基准 Excel + 供应商报价 Excel

二、快速上手（操作总流程）

  1. 准备数据：进入「📁 数据源管理」，上传所需业务表（各模块依赖的数据源见上表）
  2. 执行计算：进入对应分析模块，点击「▶ 执行分析」/「🔄 刷新宽表」生成指标结果
  3. 查看结论：阅读汇总指标、明细表格、图表，按需「📥 导出」Excel 报告

说明：回款周期、签单毛利率、资金占用等指标既支持页面即时计算，也支持后台定时任务预计算写入「宽表」，页面直接读取宽表渲染，速度更快。

三、数据源管理

所有分析模块的数据都来自这里上传的 4 张业务表，上传新版本后各模块基于最新版本计算。

  • 总合同表：合同编号、签约/统计日期、合同总金额、签单毛利、区域、部门 → 供回款周期、签单毛利率分析
  • 项目里程碑表：合同编号、回款日期/时间 → 供回款周期分析
  • 付款明细表：合同编号、实际支付时间、实际支付金额 → 供资金占用分析
  • 收款明细表：合同号、回款日期、到款金额 → 供资金占用分析

每张表支持多版本管理：上传新版本后旧版本保留，可查看历史、删除旧版本（最新版本不可删除）。

四、回款周期分析

基于总合同表与项目里程碑表，计算每个合同的回款周期，并做同比对比、分区统计。

计算方式

  • 回款周期（天） = 最后一笔回款日期 − 合同签约日期（统计日期），负值按 0 计
  • 回款周期（年） = 回款周期（天）÷ 365
  • 平均合同回款周期（天） = 各合同回款周期之和 ÷ 合同数
  • 分区口径：0–90天 / 91–180天 / 181–365天 / 365天以上

其中「最后一笔回款日期」按合同编号在项目里程碑表中取最晚的一笔回款时间。

五、资金占用 · 周转率分析

基于付款明细与收款明细，采用 FIFO 先进先出垫资冲抵算法核算每个合同的资金占用。

计算方式

  • 先按合同号 + 日期将付款、收款分别透视聚合，再按先进先出顺序冲抵
  • 预收款冲抵后续付款，生成 PRESETTLED 片段（占用 0 天）
  • 加权资金占用（元·天） = Σ（片段金额 × 占用天数）
  • 当前资金占用 = 占用中（OCCUPYING）片段金额之和
  • 预估资金成本 = 加权资金占用 × 日利率（年化 3% ÷ 365 ≈ 0.0000822）

垫资片段类型

状态含义
PRESETTLED预收款冲抵后续付款，占用 0 天
SETTLED付款已被回款结清的片段（已结清）
OCCUPYING仍在占用中的片段（未结清）

六、签单毛利率统计

基于总合同表的「签单毛利」「合同总金额」字段聚合计算。

计算方式

  • 签单毛利率 = 签单毛利 ÷ 合同总金额
  • 按年份 / 区域 / 部门维度分别聚合（签单毛利、合同总金额分别求和后相除）
  • 支持年度间同比对比（如 2026 vs 2025）

七、采购合同比对（核心功能）

本模块用于甲方采购需求清单 vs 供应商应答清单的智能文本比对。核心原则：合同是基准，供应商逐条核对。比对方向：合同要求 → 检查供应商是否满足。

典型不一致案例：

  • 需求「≥1T」vs 供应商「1T」→ 匹配通过（范围判断）
  • 需求「不低于16GB内存」vs 供应商「16GB」→ 通过（操作符归一化）
  • 需求「系统硬盘容量≥1T」vs 供应商「硬盘：1TB」→ 通过（同义词+单位换算）
  • 需求「三年原厂质保」vs 供应商「原厂3年保修」→ 通过（同义词匹配）

比对维度由主合同决定（核心）

系统以主合同为标尺：主合同有哪些列，就比对哪些列，不固化比对维度。主合同没有的维度一律不比，不会把「无此列」误判为错误。

  • 列对齐：主合同列与供应商列按列名智能对齐（如 主合同「设备名称」↔ 供应商「货物名称」），列名有差异也能自动对应。「🔍 比对结果」页顶部横向展示对齐关系，每列配一个下拉框，可手动调整主合同列对应供应商的哪一列，调整后自动重新比对。
  • 参数条件比对：主合同有「参数/规格」列才比对参数；没有则跳过，结论中不出现参数项。单价、金额等维度同理——主合同有单价/金额列才自动比对。
  • 缺列标记：供应商缺某列时单独标记（下拉框显示「无对应」），不当作错误报出。

三层比对引擎架构

系统采用「规则+NLP+语义」混合架构，由轻到重逐层递进：

输入：需求参数 A、供应商参数 B
    ↓
【步骤0：文本预处理】全角转半角、符号统一、去噪
    ↓
【步骤1：实体抽取】正则提取：指标名、操作符、数值、单位
    ↓
├─ 分支A：有数值+阈值 → 第一层 操作符归一化+单位换算+数值逻辑判断
└─ 分支B：无数字，纯描述 → 第二层 同义词匹配+编辑距离 → 第三层 语义兜底
    ↓
【输出】完全匹配 / 判断符合 / 匹配异常 / 待采购 / 供应商增项

第一层 规则引擎 — 解决数值阈值场景（核心）

能力说明示例
操作符归一化中文操作符 → 符号：不低于→>=、不高于→<=、大于→> 等 30+ 种「不少于16G」→ >=16GB
单位归一化T↔TB、G↔GB、GHz↔MHz，含跨单位换算「1T」与「1TB」等价
任意位置解析操作符不要求在开头，支持「系统盘≥64G」正确提取 op=>=, num=64, unit=GB
数值逻辑判断>=、<=、>、< 四种比较符要求≥64G，供应商256G → ✅满足
尾部标点清理自动去除「。」「，」等干扰「4T。」→ 正确提取 4TB

第二层 同义词匹配 — 解决指标名称变体

能力说明
同义词词典15组指标同义词：CPU/内存/硬盘/电源/网口/质保/带宽/防护等
Jaccard 2-gram字符级相似度，阈值>0.7判定为同一指标
Levenshtein 编辑距离兜底模糊匹配，处理拼写变体
CJK 字符覆盖中文字符≥70%覆盖即判定匹配

第三层 语义兜底 — 处理纯文本无数字场景

jieba 分词 + Jaccard 词重叠率。仅在前两层无法判定时触发，作为最后兜底。

使用流程

  1. 点击「＋ 新建合同」创建合同，填写名称、编号、签订日期
  2. 进入合同工作区 → 「📄 合同基准」→ 上传甲方采购需求 Excel
  3. 切换到「📦 供应商版本」→ 填写供应商名称 → 上传供应商报价 Excel
  4. 系统自动执行三层比对引擎，结果展示在「🔍 比对结果」
  5. 异常条目可逐条确认（✓ 确认 / ↩ 撤销），最终导出整改报告

比对结果状态说明

状态含义处理建议
匹配成功合同要求与供应商报价完全一致或满足阈值条件无需处理
判断符合通过范围判断/同义词/语义判定为符合（非精确相等）人工复核确认
匹配异常数量不一致或参数不满足要求逐条确认或通知供应商整改
待采购合同要求该设备，供应商未报价通知供应商补充报价
供应商增项供应商多报的设备，合同中无此要求确认是否需要增补

八、术语表

术语解释
总合同表（H表）合同主数据表，含签约日期、合同金额、签单毛利等字段
项目里程碑表（R表）项目回款里程碑记录表，含各合同回款时间
宽表定时任务预计算后落库的指标结果表，页面直接读取渲染，无需重复计算
FIFO先进先出（First In First Out），付款按时间先后与回款依次冲抵
垫资片段付款与回款冲抵过程中形成的资金占用区间（金额 + 起止日期）
加权资金占用（元·天）资金金额 × 占用天数 的累计值，衡量资金占用的规模与时长
PRESETTLED / SETTLED / OCCUPYING垫资片段三种状态：预收款冲抵 / 已结清 / 占用中
签单毛利率签单毛利 ÷ 合同总金额，反映合同利润水平

九、常见问题

问题解答
为什么「≥1T」和「1TB」没匹配？检查数据源版本是否为最新。v2.0 引擎已支持单位归一化，如仍有问题可能是 Excel 列名不规范导致指标提取失败。
为什么所有条目都是「待采购」？合同与供应商的设备名称/型号没有匹配上。检查 Excel 中设备名称和型号列是否完整，或尝试模糊匹配。
比对结果可以导出吗？可以。进入合同工作区 → 「📥 整改报告」→ 一键导出 Excel。
回款周期分析数据不准？先确认数据源管理中的「总合同表」和「项目里程碑表」都是最新版本，再点击「执行分析」重新计算。
资金占用数据不对？确认「付款明细表」「收款明细表」为最新版本，点击「执行分析」重新计算。
签单毛利率为空？确认总合同表已上传且包含「签单毛利」「合同总金额」列，并已执行「签单毛利指标计算」任务。
如何修改比对规则？比对引擎代码位于 backend/compare_engine.py，修改后重启服务即可。同义词词典、操作符映射表、单位换算表均可直接编辑。
