🛒 备品备件采购询比价智能体 · 业务系统说明

版本 V2.0 ｜ 面向：项目经理 / 运维结算组 / 采购人员 ｜ 本文档为纯业务描述，不含技术实现

一、系统是做什么的？

备品备件采购询比价智能体（简称「本系统」）用于帮助信息运维团队快速、规范、留痕地完成备品备件采购全过程：从"发起询价"到"收齐报价、选择成交供应商、下单确认、到货验收、台账归档"，每一步都自动通过邮件与供应商互动，并自动把所有邮件抄送给相关业务方（项目经理、结算组等），做到"全程有据可查"。

🎯 系统解决的 5 个业务痛点

#业务痛点系统给出的答案
1询价过程靠手动发邮件，抄送容易漏自动抄送所有发给供应商的邮件自动走统一抄送列表，不再需要手动加抄送
2供应商报价散落在各邮箱里，对比要手动自动汇总自动收齐所有供应商报价后形成报价汇总单，实时高亮推荐成交供应商
3项目经理审批在群里点，事后找不到证据飞书留痕审批通过消息卡片直达项目经理飞书，卡片点击"确认成交"直接留痕
4合同号、项目经理每次发起询价都要手动填，容易错集中维护合同档案集中管理，下拉一键选中，姓名/邮箱自动带出
5验收/结算要翻历史聊天记录自动台账所有询价/报价/确认/验收自动写入采购台账，可按合同号、供应商、日期筛选导出

二、系统里有哪些业务模块（左侧菜单 2 组共 5 项）

左侧菜单分 2 组：业务中心（询价任务 / 采购台账）+ 基础数据（备品备件 / 供应商 / 合同 / 抄送）。

📋 询价任务（首页）

显示所有正在进行和已经完成的采购任务，可按"进行中 / 已完成 / 已归档"等状态过滤。点击任意一条任务 → 进入【任务详情页】（左右分栏）：

  • 左侧：任务基础信息（合同名 / 备件型号 / 数量 / 创建时间）+ 操作日志（每一步谁、什么时候、做了什么）
  • 右侧：5 步垂直流程条，每一步都有【说明】【操作区】【结果摘要】
    1. 第 1 步 · 发起询价 → 显示已选中的供应商清单 + 询价邮件内容预览
    2. 第 2 步 · 等待报价 → 实时显示"已回复 / 未回复"供应商列表
    3. 第 3 步 · 报价汇总 → 报价汇总高亮卡（推荐成交供应商 = 绿色高亮 + 成交单价/总额 红色加粗醒目）
    4. 第 4 步 · 采购确认 → 显示"已发送采购确认邮件给供应商"状态
    5. 第 5 步 · 到货验收归档 → 显示"验收通过通知 / 已写入台账"状态

➕ 新建询价

用户在这里发起一次全新的备品备件采购，操作分 5 步：

  1. 选择合同（下拉选中具体合同；显示格式：合同名 + 合同号 + 项目经理）
  2. 选择备件型号（从备件库全量带出，可任意选择）
  3. 填写采购数量 / 紧急等级（2h / 4h / 5h，决定报价截止时间）
  4. 勾选供应商（系统自动带出资源池全部供应商，可勾选参与本次询价；也可在表单底部临时新增供应商：仅本次任务可见，不入库）
  5. 点击「🚀 一键发起询价」→ 系统自动给每个供应商发询价邮件 → 自动跳转回【询价任务】页查看进度
📌 设计要点：合同是核心数据，不与供应商/备件做绑定；供应商统一进资源池，新建任务时全量带出。

📊 采购台账

所有已完成采购的历史记录汇总册（审计/结算/对账用），每条记录含：合同号 · 供应商 · 成交单价 · 成交总额 · 采购数量 · 下单时间 · 验收时间。顶部支持筛选条件：合同号 / 供应商 / 下单时间区间，可随时重置回"全部"。

🔧 备品备件主数据（基础数据）

维护常用备品备件档案：编码 · 名称 · 规格型号 · 品牌 · 单位 · 分类 · 备注。新建询价时备件下拉直接从此处带出。支持新增 / 编辑 / 删除 / 按编码/名称/规格/品牌/分类搜索。

🏢 供应商主数据（基础数据 · 资源池）

维护所有合作供应商的档案：名字 + 邮箱 + 供货能力说明。供应商不与合同/备件绑定，全部进入资源池，新建询价时自动全量带出供勾选。支持新增 / 编辑 / 删除 / 按名字、邮箱、供货能力模糊搜索。

📌 业务规则：删除供应商时，如果该供应商曾出现在任何采购任务/台账中，系统会禁止删除以保留审计线索。

📄 合同主数据（基础数据 · 核心实体）

维护所有合同的档案（合同号唯一，是采购业务的唯一键），每条合同档案包含：

  • 合同名（全称，如"IT基础设施扩容合同"）
  • 合同号（英文+数字唯一编号，如 IDZB2607070A）
  • 项目经理（中文名）
  • 项目经理邮箱（接收抄送人 / 审批人邮箱）

支持搜索（合同名/合同号/项目经理名/邮箱）、新增、编辑、删除。

📌 重要业务规则：
① 合同号全局唯一，重复会拒绝保存；
② 合同名、项目经理、邮箱修改会同步到所有引用该合同的地方（采购任务、采购台账），保证信息一致；
③ 如果合同已被任何采购任务/台账引用，禁止删除以保留审计线索。

📮 全局邮件抄送（基础数据）

配置"所有发给供应商的邮件，都自动抄送哪些邮箱"（全局生效，每个任务都自动加上这些抄送），每条抄送配置含：抄送人姓名 + 抄送人邮箱。支持新增 / 编辑 / 删除 / 搜索。

📌 生效范围：以下 4 类发给供应商的邮件，都会自动抄送本列表的全部邮箱：
① 第 1 步「发起询价」询价邮件 ｜ ② 第 4 步「采购确认」邮件（确认成交后发给中选供应商）｜ ③ 第 5 步「到货验收通过」通知邮件 ｜ ④ 测试确认邮件（运维调试用）

三、典型完整业务流程（从 0 到台账归档的 5 步）

示例场景：要采购 3 块华为 AR6280 路由器主板，走完全流程。

第 1 步：发起询价（人：采购人员）

进入【新建询价】页 → 选合同「IDZB2607070A · IT基础设施扩容合同（项目经理：张启明）」→ 选备件「华为 AR6280 路由器主板」，数量=3，紧急等级=4h → 系统自动带出资源池全部供应商，勾选参与询价的：东软供应商、华为总代、运维配件供应商（3 家，也可临时新增临时供应商）→ 点「🚀 一键发起询价」

系统自动做的事：给 3 个供应商各发 1 封询价邮件 + 自动抄送给全局抄送列表（张启明 + 运维结算组） + 生成一条任务，状态=「询比价进行中」+ 写入操作日志

第 2 步：等待报价（无人为操作，系统自动轮询邮箱）

供应商回复报价邮件到系统邮箱 → 系统自动解析报价单中的单价/总价/货期，全部收齐或截止时间到后，任务状态进入「已选型确认」前的待审批态

第 3 步：报价汇总 + 项目经理审批

系统自动生成报价汇总单，按「总价最低优先 + 货期满足 + 有历史合作」算法推荐成交供应商，报价卡上：🟢 推荐成交供应商 = 绿色高亮（亮青邮箱高亮），🔴 成交单价 / 成交总额 = 红色 15px 加粗（醒目）。同时给项目经理发飞书审批卡片 → 项目经理点开卡片看报价汇总 → 点「确认成交」

第 4 步：采购确认

项目经理点「确认成交」后：系统自动给中选供应商发「采购确认邮件」（含订单号、交货地址、签收人）+ 自动抄送给全局抄送列表 + 任务状态=「供应商发货中」

第 5 步：到货验收 + 台账归档

货物到库后，采购人员在任务详情页点「✅ 验收通过」→ 系统自动给供应商发「验收通过通知邮件」+ 再次自动抄送全局列表 + 自动写入【采购台账】（合同号、供应商、单价、总额、数量、下单/验收时间一应俱全）+ 任务状态=「流程闭环」，全流程闭环

四、全局业务规则（所有业务模块都遵守）

#业务规则业务影响
R1所有供应商邮件 → 自动抄送全局抄送列表发件人不用手动加抄送；项目经理/结算组永远能收到副本，杜绝漏抄
R2合同号全局唯一合同档案里合同号不可重复；后续所有下拉引用都用合同号作唯一键
R3合同被引用不可删除合同一旦被采购任务/台账引用 → 删除按钮返回错误；只能编辑合同元信息
R4合同信息更新同步全链路修改合同名/项目经理/邮箱后，所有引用处（采购任务、采购台账）自动同步，避免信息错乱
R5供应商 = 资源池供应商不与合同/备件绑定；所有供应商自动进资源池；新建询价时自动全量带出供勾选；可临时新增临时供应商（仅本次任务可见，不入库）
R6合同 = 核心实体新建询价只需选合同 → 备件 → 数量；不再有项目层级；台账、任务均以合同为主键串联
R7审批留痕 = 飞书卡片点击项目经理的"确认成交"不可口头；必须点击飞书审批卡片上的按钮，才能触发后续流程（有操作日志记录）
R8采购台账 = 全量历史记录任何"验收通过"的任务自动写入台账，不可手动删除；用于对账、审计、年度备件盘点
R9紧急等级新建询价时，紧急等级由用户选择：2h / 4h / 5h，决定报价截止时间
R10操作日志不可删除所有模块的创建/编辑/删除/审批/验收动作都会写入操作日志，用于事后追溯

六、常见问题 FAQ（业务向）

Q1：我想加一个新的合同，合同号必须什么格式？
A：合同号建议用「类别代码 2 位 + 日期（年4月2日2）+ 流水号 1 位」，例如 IDZB2607070A = IT类 + 2026.07.07 立项 + 第A份。只要唯一就行，格式没有强制限制。

Q2：全局抄送列表里加了一个新邮箱，多久生效？
A：即时生效。下一次系统发出的任何供应商邮件都会自动带上这个抄送邮箱；无需重启或刷新。

Q3：某供应商离职/停合作了，为什么删不掉？
A：系统遵守"审计线索优先"原则——只要该供应商曾出现在任何采购任务或台账中，就禁止彻底删除；可以编辑其邮箱或备注（如标注"已停用"），历史记录保留。

Q4：项目经理审批如果没装飞书怎么办？
A：项目经理可直接用网页打开系统 → 在采购任务详情页的第 3 步（报价汇总）手动点「✅ 我是项目经理，确认成交」也能完成确认，操作日志同样记录确认人。

Q5：供应商回复的报价不是在邮件正文，而是 Excel 附件怎么办？
A：系统会自动解析邮件正文里写的"单价×数量=总价"格式；若供应商只发附件，目前需人工把附件里的单价回填到报价汇总卡（后续版本会自动解析 Excel 附件）。
